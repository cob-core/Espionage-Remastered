# v4.1 "Shadow War" — Design Spec & Plan

Date: 2026-08-01 · Status: approved ("Once fully planned implement to completion").
User decisions: Pipeline = coercive counterplay · Turned Networks = counterintel reviews ·
Great Game = every spy agency · Sealed Train = surge + spark · **False Flags = every
action (user override of recommended subset)** · Kompromat = networks build dossiers ·
Dynamic odds = ±15%/level.

## Identifier plan

- Events: `adv_dip_event` **150–154** pipeline · **160–162** turned networks ·
  **165–166** Great Game · **170–172** Sealed Train · **175–176** false flags ·
  **180–181** kompromat. No `flavor` fields (halves loc surface; vanilla-legal).
- Actions: `a13_clandestine_arms_pipeline` (pact) · `a15_sealed_train` (instant) ·
  `a16_false_flag_directive` (instant, targets the patsy).
- Core values: `target_espionage_plus/minus_1..3` (pact scope) and
  `spy_target_espionage_plus/minus_1..3` (event scope) power all differential triggers.
- Variables: `pipeline_attribution`, `turned_<action>_by` (scope), `great_game_score`,
  `global_var:great_game_leader`, `kompromat_dossier_progress`, `false_flag_patsy`
  (60-mo), cooldowns `recently_sealed_train`, `recently_pipeline`.
- Hooks (append-only on_actions): `adv_dip_espionage_yearly` on `on_yearly_pulse_country`
  (turned-network reviews, kompromat accrual, Great Game decay).

## Feature contracts

1. **Pipeline**: pact (cost 150 + `income_transfer 0.10`), target `is_at_war`,
   maintained only while at war; recipient gets `sponsored_war_effort_modifier`.
   Monthly gauntlet event `.150` (interception ~1/9, naval-ratio + edge scaled):
   money loss + `pipeline_attribution` +1; at 3 → `.151` on the strongest enemy
   (reveal + Demand Cessation choice) → `.152` ultimatum on sponsor (comply: pact ends,
   −prestige, recipient morale dent · refuse: infamy + enemy relations floor).
   `auto_break_effect` → `.153` payoff: recipient survived the war → obligation +
   decaying prestige (`pipeline_triumph_modifier`); Great Game major score.
2. **Turned Networks** (sow discontent, election interference, steal tech): X1 events
   save `scope:spymaster`; X2 events gain option "Turn their network" (visible with
   espionage edge ≥1): sets `turned_<x>_by`, upkeep `counterespionage_modifier`, no
   relations hit. Poisoned X1 paths: spymaster pays, real payoff skipped; poisoned tech
   adds `stolen_technology_poisoned_modifier` (research −5%, **localized identically to
   the real modifier** — the deception is the feature). Yearly review `.160` on the
   spymaster (discovery weighted by edge) → reveal `.161`/defender `.162` (vars cleared,
   pact removed, prestige swing, defender scores big).
3. **Great Game**: permanent JE `adv_dip_je_great_game` (visible with Spy Agency law);
   `great_game_score_minor/major_effect` called from every success event (+1/+3);
   yearly decay ×0.9; leadership check swaps `master_of_the_great_game` modifier
   (+5% prestige, +5% leverage generation) with `.165` (crowned) / `.166` (deposed).
4. **Sealed Train**: instant action, esp ≥4 + `mass_communication`, very-large cost,
   60-mo cooldown. Roll `.170` (edge-weighted): success `.171` on target — radicals
   +0.10, `sealed_train_ferment_modifier` (movement radicalism +50%, 24 mo), 1/6 spark
   (further +0.15 radicals); failure `.172` — infamy +5, −30 relations, target gains
   `sealed_train_crackdown_modifier` (movement radicalism −25%). Exile-pool character
   integration deferred (docs note) — effects restricted to verified vocabulary.
5. **False Flags**: instant directive action targeting the patsy: sets
   `false_flag_patsy` (60 mo) + `false_flag_operations_modifier` cost. Every
   event-driven detection (tech/commander/designs/pipeline/sealed-train failure)
   reroutes: victim gets `.175` blaming the patsy (victim↔patsy relations −30);
   unravel sub-roll (tier + edge scaled) → `.176`: both learn, relations collapse with
   both, infamy, target double-scores. **Engine limitation recorded**: pact ownership
   in the diplomacy UI cannot be faked; false flags cover event-driven attribution only.
6. **Kompromat**: yearly accrual (`kompromat_dossier_progress` + 1 + edge) while any
   espionage pact runs; at 5 → `.180`: choose **Disgrace** (enemy commander
   busy-and-immortal, freed by `.181` a year later), **Ruin** (`remove_character_role`
   — career over, −20 relations if traced 1/3), or **Scandal** (target
   `kompromat_scandal_modifier`: −5% prestige + radicals). Dossier resets; stale rule:
   progress zeroes if no espionage pact remains.
7. **Dynamic Odds**: all pact monthly dice rescaled ×100 with factor stacks on the hit
   entry (≥+1/+2/+3 edge: ×1.15 each ≈ +52%; deficits ×0.85 ≈ −39%); detection entries
   get the inverse (×0.9 / ×1.1 per tier). Same stacks power reviews, unravels, rolls.
