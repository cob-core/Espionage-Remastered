# v4.0 Completion Set — Design Spec

Date: 2026-08-01 · Status: **approved by user** ("Approve the last feature set and
implement also"). Part 1 of the v4.0 release; part 2 (naval/blackmail set) has its own
spec once vanilla research lands.

## Approved decisions

- **Steal Commander:** true defection via `transfer_character` (vanilla-proven in
  obligation events); sibling-scale X1/X2 event pair; one-shot heist — success burns the
  pact and starts a multi-year cooldown.
- **Sabotage Recruitment:** polished to sibling quality (events exist; loc does not).
- **Develop Nation:** JE completes with sweetened reward — Recognition + relations +
  obligation + `development_gratitude_modifier` (target) + decaying prestige (root).
- **Sabotage Industry:** fully removed (action, modifier, events `.51`/`.52`, docs,
  description.bb line). Saves holding the pact drop it with a benign log line.
- **Graduation:** `TODO/` folder deleted; survivors move to `common/diplomatic_actions/`
  as `a06_sabotage_recruitment.txt`, `a09_steal_commander.txt`, `a17_develop_nation.txt`.
  Action **keys** unchanged (save compat).

## Steal Commander (action `steal_commander`)

Fixes to the action itself:
- `requires_approval = yes` → **no** (a spy action cannot ask the victim's consent).
- Pact cost 100 → **150** (tier with steal_technology).
- Monthly dice: 1/101 → **1/34** (`33 = {}` / `1 = {...}`), firing **`adv_dip_event.131`**
  (not the steal-tech placeholder), guarded on `NOT has_variable = recently_stole_commander`.
- `should_invalidate` additionally: target has no eligible commander
  (general/admiral, not ruler, not busy), or root has `recently_stole_commander`.
- AI: dedupe the doubled `expert_offensive_planner` trait weight.

**`adv_dip_event.131` (initiator):** immediate — find `spy_target_country` by pact scan;
`random_character` in target (general/admiral, NOT ruler, NOT busy) →
`save_scope_as = steal_commander_target`. Options:
- **a) Bring them over:** `transfer_character = root`; cost
  `spy_network_cost_modifier` × `spy_cost_multiplier_medium` (25 mo); target −20 relations;
  `set_variable = { name = recently_stole_commander months = 60 }`;
  `remove_diplomatic_pact` (the network is burned); 1-in-3 detection →
  `trigger_event = adv_dip_event.132` at target (defection is loud — higher than
  steal-tech's 1/6).
- **b) Keep them in place as an asset:** no transfer; small counterespionage-flavored
  bonus — `add_modifier = commander_asset_modifier` (root, 24 mo, new modifier:
  `country_intel_...`→ use `country_influence_add = 25`-class benefit? No: keep concrete —
  `unit_army_offense_add = 2`-class is wrong scope; use existing pattern: root gains
  `military_attache`-style tech spread? **Decision: option b grants
  `stolen_technology_military_modifier` (existing, 24 mo)** — the asset feeds you doctrine
  papers. No transfer, pact continues, no cooldown.
- **c) Abort** (default): nothing.

**`adv_dip_event.132` (target):** notification in recipient voice; target gets
`recent_defection_modifier` (new, 36 mo: `country_prestige_mult = -0.05`,
`interest_group_ig_armed_forces_approval_add = -2` — the officer corps is shaken) and the
initiator's identity is revealed (−20 relations already applied).

## Sabotage Recruitment (action `sabotage_recruitment`)

- Add `groups = { general }`, institution gate **level ≥ 3**, `has_diplomatic_relevance`,
  `NOT has_war_with` in `possible`, pact cost 100 → **150**.
- Events `.41`/`.42` kept structurally; `.42` applies `sabotage_recruitment_modifier`
  (existing, valid types) for 25 mo + `add_radicals = 0.02` conscript-flavored unrest.
- **Full loc set** (currently zero keys): action sextet + `_monthly_effect` + trigger
  triads + `.41`/`.42` t/d/f/options — english + french.

## Develop Nation (action `develop_nation`)

- Remove the orphan `effect = { save_scope_as = develop_nation_target }` from the action.
- `.111` (success) option gains: `change_relations = 50`,
  `set_owes_obligation_to = { country = root setting = yes }` (on target),
  target `add_modifier = development_gratitude_modifier` (new, 60 mo:
  `country_leverage_resistance_mult = -0.25`, `country_improve_relations_speed_mult = 0.10`),
  root `add_modifier = successful_development_modifier` (new, 13 mo decaying:
  `country_prestige_add = 25`), alongside the existing `set_country_type = recognized`.
- `.112` (fail) unchanged mechanically (cleanup already fixed in v3.6).
- a17 monthly dice guard already fixed in v3.6.

`commander_asset` need is covered by the existing `stolen_technology_military_modifier`;
new: `recent_defection_modifier`, `development_gratitude_modifier`,
`successful_development_modifier` — icons from vanilla timed_modifier_icons.
