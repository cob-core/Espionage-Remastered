# v4.0 Naval & Blackmail Set — Design Spec

Date: 2026-08-01 · Status: user-directed ("plan, brainstorm, and implement"); design
decisions delegated — recommended options chosen and recorded here. Part 2 of v4.0.

## Research grounding (agent survey of vanilla 1.13.9, key findings)

- The Great Wave flag = **`ep2_content`**; hooks ship in base 1.13.9 (DLC not owned
  locally — ep2 paths are static-verified only).
- Flagships scriptable: `is_flagship` (ship), `any_scope_ship`/`random_scope_ship`,
  `damage_ship_percent` (effect exists via effect-localization; **no vanilla usage —
  runtime-unverified**), on_flagship_* on_actions.
- Piracy: **no per-country targeting, no victim-side piracy modifier.** Valid levers:
  `country_piracy_income_add`, `country_port_connection_cost_mult`,
  `building_port_throughput_add`, `country_prestige_from_navy_power_projection_mult`.
- Ship *templates* not script-visible → Steal Ship Designs = construction/doctrine
  espionage (`country_ship_construction_efficiency_add`, `country_military_tech_spread_mult`).
- Treaty-article anatomy: `non_fulfillment { consequences conditions }`,
  `inherent_accept_score`, `article_ai_usage`; enforceability skipped (sibling scale).
- Invalid legacy type found: `unit_navy_offense_mult` (piracy_disruption_modifier) →
  replace with `ship_hull_damage_mult`.

## Feature 1 — Naval Intelligence Network (flagship, assassination-mold)

- **Action** `naval_intelligence` (`a11_naval_intelligence.txt`): esp ≥ 3, tech
  `battlefleet_tactics`, target `navy_size >= 5`, cost 200, one-sided, no approval.
  Deterministic monthly fire of `adv_dip_event.140` gated on
  `NOT has_variable = ongoing_naval_intel`; invalidates on war/decentralized/default/
  cooldown var `recently_ran_naval_intel`.
- **JE** `adv_dip_je_naval_intelligence` (target = spy target), bars
  `naval_intel_progress_bar` (0→10) vs `naval_intel_risk_bar` (0→10);
  `on_monthly_pulse` table (weight 30 = quiet) over flavor events `.141`–`.146`
  (dockyard clerk, signals intercept, harbor courtesan, counterintel sweep, drunken
  attaché, double agent) nudging bars via `adv_dip_naval_intel_effects.txt`
  (guard-mutate-tooltip pattern, mirroring assassination effects).
- **Buttons**: `je_fund_informants` (+2 progress, cost `naval_intel_cost_modifier` ×
  `spy_cost_multiplier_small` 13 mo, cooldown 6 mo), `je_burn_contacts` (−3 risk,
  −1 progress, cooldown 12 mo).
- **Complete** (progress ≥ 10) → `.148` capstone choice:
  a) **Crack their codes**: root `naval_codebook_modifier` 36 mo
     (`ship_accuracy_mult = 0.10`, `ship_visibility_mult = -0.10`);
  b) **Sabotage the flagship** (visible only with `has_dlc_feature = ep2_content` and
     target flagship existing): flagship `damage_ship_percent = 0.5`
     (runtime-unverified, flagged), target `humiliated_navy_modifier` 12 mo
     (`country_prestige_mult = -0.05`), −20 relations;
  c) **Landing charts**: root `naval_landing_intel_modifier` 36 mo
     (`unit_naval_invasion_efficiency_mult = 0.25`, `ship_supply_efficiency_mult = 0.10`).
  All paths: pact removed, `remove_naval_intel_effect` cleanup, cooldown 36 mo.
- **Fail** (risk ≥ 10 or pact lost) → `.149`: −30 relations, root
  `exposed_spy_ring_modifier` 24 mo (`country_influence_mult = -0.10`), cleanup.

## Feature 2 — Steal Ship Designs

- **Action** `steal_ship_designs` (`a12_steal_ship_designs.txt`): esp ≥ 2, tech
  `ironclad_tech`, target `naval_combat_power > root.naval_combat_power`, cost 150,
  dice 1/17 → `.135`; NOT DLC-gated (all payoff types are base).
- **`.135`** (initiator): option a — root `stolen_ship_designs_modifier` 24 mo
  (`country_ship_construction_efficiency_add = 0.15`,
  `country_military_tech_spread_mult = 0.25`), cost medium, 1/6 detection → `.136`,
  −10 relations on detection; option b — decline.
- **`.136`** (target): recipient-voice notification (no mechanical sting, mirroring
  steal-tech's `.92`).

## Feature 3 — Fund Piracy rework

- `local_piracy_modifier` (victim) re-expressed:
  `country_port_connection_cost_mult = 0.2`, `building_port_throughput_add = -0.10`,
  `country_prestige_from_navy_power_projection_mult = -0.10`.
- `piracy_disruption_modifier`: invalid `unit_navy_offense_mult` →
  `ship_hull_damage_mult = 0.10`.
- **ep2 layer**: `.101` gains option "Arm the corsairs" (visible with
  `has_dlc_feature = ep2_content`): initiator additionally gets
  `corsair_patron_modifier` 24 mo (`country_piracy_income_add = 0.10`) — a cut of the
  real piracy economy — at a higher cost tier (large) and −5 further relations on
  discovery. Free-patch path keeps existing behavior with the fixed modifiers.

## Feature 4 — Blackmail (treaty article)

- **Article** `blackmail_concession` (`common/treaty_articles/adv_dip_blackmail.txt`):
  `kind = directed`, `cost = 50`, `maintenance_paid_by = source_country`,
  `usage_limit = once_per_side`, icon reuses `chess.dds` (existing mod art).
  - `visible`: source esp ≥ 4.
  - `possible`/`can_ratify`: source holds **any espionage pact** with target (the
    dossier): OR over sow_discontent / support_nationalists / agitate_for_liberty /
    steal_technology / election_interference / fund_piracy / support_slaves /
    sabotage_recruitment / steal_commander / naval_intelligence / steal_ship_designs.
  - `source_modifier`: `country_leverage_generation_add = 10`;
    `target_modifier`: `country_leverage_resistance_mult = -0.5`.
  - `non_fulfillment`: weekly condition — the espionage network no longer exists →
    `consequences = withdraw` (**stale dossiers collapse the blackmail**).
  - AI: `article_ai_usage = { request }`; `inherent_accept_score` gives the target
    side +40 (the dossier is leverage) scaled down by rank superiority.
  - Enforceability (`can_be_enforced` + wargoal_data) deliberately omitted this
    release; recorded as future work with gunboat-acceptance integration.
